# Catatan CLI

Aplikasi catatan sederhana di terminal. Python 3, tanpa dependensi tambahan.

## Cara pakai

```bash
python catatan.py tambah "Beli susu"
python catatan.py daftar
python catatan.py cari susu
python catatan.py hapus 1
```

Catatan disimpan di file `catatan.json` di folder yang sama.
